GLASSY STEEL LEDGER PRO — ROLE-BASED STAFF PERMISSIONS

Files:
- index.html
- style.css
- script.js

WHAT'S INCLUDED
- Seven predefined roles: Super admin, Manager, Accountant, Sales officer,
  Store keeper, Read-only viewer, and Custom staff.
- A role overview card layout in Admin Panel.
- Per-staff permission editor with grouped modules and individual actions.
- Each permission clearly shows CAN DO / CANNOT DO.
- Role templates can be selected, then individually customized.
- Admin Panel and user/role management remain Super admin only.
- Permission checks protect the relevant create, edit, delete, print, export,
  convert, backup, restore, business-settings, and reset actions.
- Existing browser localStorage data keys are preserved.

HOW TO USE
1. Extract the ZIP into one folder.
2. Open index.html in Chrome or Edge.
3. Sign in with your administrator account.
4. Open Admin Panel.
5. Add a staff member and choose a role, or click Permissions beside an
   existing staff member.
6. Select a role template, adjust individual permissions, then Save permissions.

ROLE PRESETS
- Super admin: unrestricted access; Admin Panel and role management.
- Manager: broad day-to-day business operations.
- Accountant: billing, payments, ledgers and financial exports.
- Sales officer: customers, rates and quotations.
- Store keeper: stock and steel-grade inventory.
- Read-only viewer: view-only access to permitted sections.
- Custom staff: basic access, fully customizable by the administrator.

IMPORTANT
This application stores data in the current browser's localStorage. Staff
accounts and permission settings are browser-local and are not synchronized
between computers. This is not server-side authorization; for multi-device
or internet-hosted use, add a secure backend and server-side permission checks.
